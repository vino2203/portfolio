Main project

Scheme assistant for Tamil Nadu farmers

A chat assistant where a farmer can ask in Tamil or English and find out which state and central schemes they can apply for.

Why I built it

Scheme details are spread across many government sites and PDFs, mostly in English. If a farmer asks a simple question in Tamil, it's hard to get a clear answer on eligibility, subsidy amount or which documents to bring.

What it does
  • I wrote a BRD first and built from that.
  • Ask in Tamil or English, get the answer in the same language.
  • Choose Tamil Nadu schemes, central schemes, or both.
  • Search uses both meaning and keywords, so scheme names and local words still match.
  • A knowledge graph suggests related schemes. If it's down, normal search still works.
  • Upload land records or certificates to check eligibility.

Personal AI agent

Telegram bot that runs Claude on my Mac

NEW · WORKING

I send a message to my own Telegram bot. n8n on my Mac picks it up and passes it to Claude Code, which answers using my Claude Pro subscription. Claude can search the web, so it can handle things like the weather today or the latest version of a tool. In my last test the reply came back in about 5 seconds.

Telegram→Only my chat→n8n→Claude Code→Reply

Only my chat can use it. Messages from anyone else, and anything that isn't text, are dropped before they reach Claude. There's no API bill, it runs on the subscription I already pay for.

Getting it working taught me a lot: Telegram webhooks through a tunnel, n8n's newer publish flow, and a bug where my message reached Claude empty.

How I work

How I build AI apps

The same few habits show up in every project above.

01

Start with the requirement

I write down who it's for and what a good answer looks like before I touch code. The farmer assistant started as a BRD.

02

Get retrieval right

Most bad answers come from bad search. I mix vector search, keyword search (BM25) and a Neo4j knowledge graph so the right text actually comes back.

03

Measure the answers

Coming from testing, I don't trust "looks fine". I score answers for relevance and faithfulness with DeepEval and trace runs in LangSmith.

04

Keep a person in control

Guardrails for off-topic questions, citations so you can check the source, and an approval step before anything gets sent.
